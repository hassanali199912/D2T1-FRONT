# front

Private Vite SPA for the insurance dashboard.

## Docs

- [Quick start and 5-minute demo](docs/README.md)
- [System design (MVP) and gap table](docs/SYSTEM-DESIGN.md)

## Commands

```bash
npm install
copy .env.example .env
npm run dev
```

API base URL: `VITE_API_BASE_URL` (see `.env.example`). The Nest API must be running and CORS must allow `http://localhost:5173`.
